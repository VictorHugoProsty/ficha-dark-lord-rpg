Como funciona esse compêndio
Fica salvo só na sua conta (neste navegador, e na nuvem se você estiver logado) — ninguém mais vê.
Magias: use a busca por nome, o filtro de tipo ou o círculo (exato) pra encontrar a magia no compêndio (a lista completa só aparece quando algum filtro está ativo). O botão "Usar" joga a magia direto pro campo do círculo certo na ficha.
Poderes: cadastre nome/link, ou importe um JSON com grupo/pré-requisito/descrição pra ver tudo no botão ℹ️. O botão 🔗 abre o link; o botão "Usar" joga o nome direto pras Habilidades de Classe.
Perícias e Condições: importe os JSONs de referência aqui e as descrições aparecem direto nos botões ℹ️ das abas Perícias e Atributos, sem precisar de tabela própria.
Equipamento: busque armas, armaduras/escudos ou itens (a lista só aparece com busca ativa) e clique "Usar" pra jogar direto nas tabelas de Armas/Armadura (aba Combate) ou Equipamento.

Como deixar essa ficha à mão no celular
Tudo que você digita aqui já salva sozinho neste navegador, neste aparelho — não precisa clicar em nada para isso.

Para levar os dados preenchidos para o celular (ou mandar para outra pessoa), use o botão Link com dados: ele copia um link que já abre com a ficha preenchida, sem precisar de arquivo.

O botão Exportar baixa um arquivo .json como backup — use Importar para carregar esse arquivo depois.

No iPhone (Safari): toque em Compartilhar → Adicionar à Tela de Início.
No Android (Chrome): toque no menu ⋮ → Adicionar à tela inicial / Instalar app.
